# china-terrain-maps

Vivid 3D terrain renders, an interactive 3D web map, and 3D city models (Chongqing, Hong Kong) of China,
built entirely from open data: Copernicus DEM, GEBCO 2026, GEDTM30, Natural Earth, Overture Maps,
GlobalBuildingAtlas, and Sentinel-2.

Work in progress. See the plan in the first commits. Full docs will follow.
